# AuraPlus-API

A secure, full-featured messaging API built with **FastAPI** that provides all the essential features for real-time communication applications. This API enables user authentication and account recovery, private and group messaging, media uploads, typing indicators, online status tracking, and secure password management through security questions.

Designed with scalability, modularity, and performance in mind, this backend system can serve as the foundation for mobile or web chat applications. It includes JWT-based authentication, organized route handling, database integration with PostgreSQL.

##  Endpoints Overview

###  Authentication
- `POST /register` – Register a new user
- `POST /login` – Login and retrieve token

###  Profile
- `GET /profile` – Get current user’s profile (requires token)
- `POST /update-user-photo` – Upload or change profile photo
- `POST /get-user-photo` – Get profile photo

###  Password & Security
- `POST /check_security_answers` – Validate security questions
- `POST /forgetupdate_password` – Update password with security validation
- `POST /update_password` – Update password (old + new)

###  Online Status
- `POST /update-online-status` – Mark user as online/offline
- `POST /get-online-status` – Check if user is online

###  Messaging
- `POST /messages` – Send a message
- `GET /messages/{chat_id}` – Get all messages from a chat
- `DELETE /delete-message/` – Delete a message

###  Group Chats
- `POST /create_group` – Create a group
- `POST /get_user_groups` – Get all user’s groups
- `DELETE /delete-group/` – Delete a group
- `GET /group_messages/{group_id}` – Fetch messages from a group
- `DELETE /delete-group-message/` – Delete a message from a group

###  Typing Status
- `POST /update-typing-status` – Update typing status
- `GET /typing-status/{chat_id}/{username}` – Get typing status of user in chat

###  Media
- `POST /upload-media/` – Upload media (image, file, etc.)
- `GET /get-media/?link=...` – Access uploaded media

###  Utility
- `GET /check-username?username=` – Check if a username exists
- `POST /get-users` – Get all contacts
- `POST /create_or_get_chat` – Start or get existing chat
- `POST /get_user_chats` – Get all chats of a user
- `POST /check-group-creator` – Verify group creator

##  Dependencies & Setup

This project uses the following key libraries and modules:

###  Python Standard & Third-Party Libraries

| Library            | Purpose                                           |
|--------------------|---------------------------------------------------|
| `fastapi`          | High-performance web framework for APIs          |
| `pydantic`         | Data validation and settings management           |
| `uvicorn`          | ASGI server to run FastAPI                        |
| `passlib`          | Password hashing (e.g., bcrypt)                  |
| `jwt` (`pyjwt`)    | JSON Web Tokens for authentication                |
| `psycopg2`         | PostgreSQL database driver                        |
| `base64`           | Encoding/decoding (e.g., for media uploads)      |
| `os`               | Environment/file operations                       |
| `datetime`         | Handling timestamps and token expiry              |
| `typing`           | Type hinting with `Optional`, `List`, etc.       |
| `shutil`           | File operations                                   |
| `starlette`        | CORS, responses, and WebSocket support           |

###  Middleware
- `CORSMiddleware` from Starlette to allow cross-origin resource sharing (e.g., for frontend clients)

###  Security
- `OAuth2PasswordBearer` is used for token-based authentication (via `/login` endpoint).
- JWTs are used for secure, stateless user sessions.

###  Database
- PostgreSQL is used for relational data storage (via `psycopg2` connector).
